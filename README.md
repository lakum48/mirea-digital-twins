# Программирование цифровых двойников

Папка CityWorkshop открывается через Unity Hub в Unity 6000.4.3f1. Сцены расположены в Assets/Scenes; управление и порядок запуска описаны в файле [Как открыть проект](CityWorkshop/Запуск.md).

В notebooks/telemetry размещены блокнот анализа строительной площадки и телеметрия из Unity. Для notebooks/regression нужен файл «Гиперспектр кукурузы.csv» из задания. Поместите его рядом с блокнотом.
